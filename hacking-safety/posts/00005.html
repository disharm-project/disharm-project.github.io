Twitter embed workaround how to make

Substack is moving so fast, with new features and changes to existing features being delivered every month. It’s great if you are a Substack user, but not so great if you are writing a book about how to use Substack, because everything keeps changing. The clip above is from TikTok. Embedded TikToks and YouTubes are a nice way to add some colour and movement to a Substack post without having to create your own videos. I used tweets in a similar way in my main Substack. But the feature that allows us to embed tweets is gone now. That sucks. Hey there, this is Pubstack Success where I help you succeed on Substack. If you aren’t already subscribed, do that now. I send one helpful email per week and I don’t use your email address for anything else. Here’s what an embedded tweet used to look like in a post: Since Twitter and Substack had an argument in early April, the automatic embedding feature no longer works tweets. Now, if you paste a link to a tweet you get a ‘raw’ URL instead 😞. I want to keep using Tweets, not least because my audience relies on me to collect interesting news for them, so they don’t have to waste their precious time hanging out with the dirty blue bird 🐤. So I found a workaround. It’s not perfect but it’s not too bad. To create a feature in your Substack post that looks and works like an embedded tweet, follow the steps below. Take a screenshot of the tweet and paste it into your draft Substack post. In your draft post, select the image by clicking it. You will see a blue line around the image. While the image is selected, click the link embed editing tool in the post editor ribbon. A link window will pop up. Paste the tweet’s link into the pop-up window and click ‘Done’. This adds a link to the image, which will open when the image is clicked. The result is an image that looks like a tweet, which, when clicked, opens the actual tweet on Twitter. 🐤🐤 🐤🐤🐤 Hope this was helpful to you! If it was, please re-stack it to Notes by clicking the RE-STACK button. This will help other people to see it. Have a great week. Karen P.S. If you aren’t already subscribed, please do that now. I send one helpful email per week and I don’t use your email address for anything else. Funny how we'll keep embedding Tweets on here even with Musk doing all he can to prevent us.. I wish some dev came up with a dual solution for Tweets in Substack and a social preview for Substack in Tweets? Is Musk smarter than all the devs on Substack? This is gold. Thank you <3 !

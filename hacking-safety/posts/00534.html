The full conversation view is supported if the mailbox is added as an account. It does not if it is added as a shared mailbox because the conversation view only displays for messages in the folder and not for messages from other folders. This is so that the full conversation view can find the messages that belong together since search is per folder in shared mailboxes. ‎May 20 2019 05:40 AM

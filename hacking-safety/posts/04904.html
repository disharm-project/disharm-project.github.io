Error message is trying to convey that the schema extension cus:Address is exhibiting circular dependancy. In other words, a schema extension should be extending someother schema but in your case it is trying to extend itself. Can you please add screenshot for cus:address schema definition to help us pin point on the problem. View solution in original post

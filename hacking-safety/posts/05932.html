Parameters

K

-

Description

•

type(expr, algext) checks for an algebraic extension by determining if expr is a root of a univariate polynomial specified by a RootOf. •

type(expr, algext(K)) checks whether expr is a RootOf of a univariate polynomial with coefficients in the domain K. For example, K could be integer, rational, or a more complicated type like polynom(algnum). Examples

>
